# ssh-agent-crypt

Dateiverschlüsselung und -entschlüsselung mithilfe eines laufenden SSH-Agents (`SSH_AGENT_SOCK` / `SSH_AUTH_SOCK`) mit Unterstützung für mehrere SSH-Keys, die jederzeit hinzugefügt und entfernt werden können – ohne Secrets auf der Kommandozeile.

*(Dokumentation wird nach Abschluss der Implementierung vervollständigt.)*
